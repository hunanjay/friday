# Chat 端到端手工测试用例

覆盖邮件 / 日历 / 联系人 / GitHub 日报四个领域 Agent，在正式环境的 Chat 里逐条发送下面的话术，对照“预期路由”“预期应调用”“绝不能出现”“通过标准”核对结果。

> 这些用例来自 `backend/tests/data/agent_eval_set.json`（自动化 eval 的 goldset），自动化版本用的是虚构的联系人/邮件/事件名字（如“李娜”“周子丰”“产品评审”），手工测试时请按每条的“前提/测试数据”替换成你账号里真实存在的人和事，否则模型会如实告诉你查不到。

共 26 条，按领域分组。
